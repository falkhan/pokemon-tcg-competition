## 2026-08-04 — Phase 1 measurements, as they landed

**Attack-cost multiplicity (decides the 1b normalizer).** Over `_ATK` (1,556
attacks): per-type multiplicity histogram {1: 1459, 2: 493, 3: 139, 4: 18,
5: 2}; the only 5s are all-colorless costs (e.g. attack 41, `(0,0,0,0,0)`).
Cost size histogram {0: 5, 1: 670, 2: 447, 3: 364, 4: 62, 5: 8}; 1,069 typed
(69%, matching the M42 review). Decision: the plan's `/3` stays **unclipped**
— a clip would alias 3-colorless against 5-colorless, the exact disease this
block kills; 5/3 ≈ 1.67 is bounded and ordinal.

**The aliasing kill, first run (ours-only spec, width 144): 879 → 259, NOT
0.** Baseline at width 100 reproduced the M42 numbers exactly (879 real /
9,807 harmless / 5,319 menus / 407 affected). At width 144 the residual was
258 real::CARD + 1 real::ENERGY. Diagnosis (raw option fields of every
residual group): **ALL foreign-board options** — DAMAGE (91 groups) and
DAMAGE_COUNTER (53) spread-target submenus plus gust-SWITCH (21) address the
OPPONENT's Pokemon via `area`+`playerIndex`. The plan's "0 foreign-board
options in 4,388 prompts" premise had only examined the `inPlay*` fields.
The plan's ours-only 1a spec and its pre-registered 0-bar were in direct
conflict on this corpus.

**Piotr's call (2026-08-04): encode foreign subjects, add `is_opponents` as
board slot 7, width 144 → 145.** Blind damage-target menus (dragapult's
spread) were the most decision-relevant residual. Ownership resolves on the
board `playerIndex` names — the :207 trap (foreign index silently read on OUR
board) stays impossible by construction.

**The aliasing kill, second run (width 145): real::\* == 0.** No menus with
real aliasing. `harmless_true_duplicates` read **9,176**, not the plan's
"~9,807 unchanged": `bench_index` splits same-id same-state pairs at
different slots, which the probe's slot-blind fingerprint classes harmless —
those pairs stop being aliases altogether. Nothing decision-relevant is lost.
