## 2026-08-04 — Phase 1 measurements, as they landed

**Attack-cost multiplicity (decides the 1b normalizer).** Over `_ATK` (1,556
attacks): per-type multiplicity histogram {1: 1459, 2: 493, 3: 139, 4: 18,
5: 2}; the only 5s are all-colorless costs (e.g. attack 41, `(0,0,0,0,0)`).
Cost size histogram {0: 5, 1: 670, 2: 447, 3: 364, 4: 62, 5: 8}; 1,069 typed
(69%, matching the M42 review). Decision: the plan's `/3` stays **unclipped**
— a clip would alias 3-colorless against 5-colorless, the exact disease this
block kills; 5/3 ≈ 1.67 is bounded and ordinal.

**The aliasing kill, first run (ours-only spec, width 144): 879 → 259, NOT
0.** Baseline at width 100 reproduced the M42 numbers exactly (879 real /
9,807 harmless / 5,319 menus / 407 affected). At width 144 the residual was
258 real::CARD + 1 real::ENERGY. Diagnosis (raw option fields of every
residual group): **ALL foreign-board options** — DAMAGE (91 groups) and
DAMAGE_COUNTER (53) spread-target submenus plus gust-SWITCH (21) address the
OPPONENT's Pokemon via `area`+`playerIndex`. The plan's "0 foreign-board
options in 4,388 prompts" premise had only examined the `inPlay*` fields.
The plan's ours-only 1a spec and its pre-registered 0-bar were in direct
conflict on this corpus.

**Piotr's call (2026-08-04): encode foreign subjects, add `is_opponents` as
board slot 7, width 144 → 145.** Blind damage-target menus (dragapult's
spread) were the most decision-relevant residual. Ownership resolves on the
board `playerIndex` names — the :207 trap (foreign index silently read on OUR
board) stays impossible by construction.

**The aliasing kill, second run (width 145): real::\* == 0.** No menus with
real aliasing. `harmless_true_duplicates` read **9,176**, not the plan's
"~9,807 unchanged": `bench_index` splits same-id same-state pairs at
different slots, which the probe's slot-blind fingerprint classes harmless —
those pairs stop being aliases altogether. Nothing decision-relevant is lost.

**Column safety: PASS at widths 100 and 115 over 31,021 real options.**
Instrument correction recorded in the plan: the digest is CORPUS-relative
(hashes encodings over `replays/**`), so the plan's pinned hex from the M42
corpus proves nothing today — the script's own `--out`/`--compare` contract

## 2026-08-04 — Phase 3.2: the census fires, and kills half of 1b

`scripts/m41b_feature_census.py` over the same 31,021 options, 30 slots at
width 145. The pre-registered bar (<1% nonzero on applicable options, or
zero variance → DROP) hit **11 slots**, splitting into two classes:

**Structurally dead — a genuine engine discovery.** `colorless_deficit` ≡ 0
and `can_afford_now` ≡ 1 across ALL 1,272 ATTACK options: **the engine never
offers an unaffordable attack.** Affordability is enforced upstream of the
menu, by rule. The plan's 1b rationale ("affordability is a type question")
holds for planning, but as an OPTION feature both slots are constants. The
matching-problem deficit was implemented, measured, and removed — exactly
the honest-scoping outcome 1b pre-announced ("Phase 3's census is what
decides").

**Corpus-starved, not dead.** cost.type_{3,4,6,8,9,10,11} and both resist
flags read 0 because 27 replays span 4 matchup families (energy types
0/1/2/5/7 present, no active-vs-active resist pairing occurred). Killing
histogram slots because no Lightning deck is in the QC corpus would rebuild
deck-specificity — the exact thing this block removes.

**Piotr's call (2026-08-04): drop the 2 structurally dead slots only, width
145 → 143.** Bar amended: the kill applies to structural deadness; starved
slots are exempt (marked `starved (exempt)` by the instrument), re-censused
when a broader corpus exists.

**Re-verification at 143:** aliasing kill still `real::* == 0` (dropping
constant slots merges nothing — harmless 9,176 unchanged); column safety
PASS at 100 and 115 (same before-snapshots); census clears (28/28 surviving
slots ok or exempt); suite 1,070 + the known 4. Live census values worth
keeping: `board.has_object` fills on 47.5% of applicable options,
`is_opponents` on 3.4% (the foreign menus are real but rare),
`matchup.opp_weak_to_mine` on 18.6%, `econ.retreat_cost_4` on 96.6%.
