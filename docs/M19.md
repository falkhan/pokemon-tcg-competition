# M19 diary — defect-repair milestone (attach waste + save-the-active)

Scope set by Piotr 2026-07-19: fix the two replay-observed piloting defects

## 2026-07-19 morning — root-cause + instrumentation (pre-pipeline)

- **New instrumentation shipped-ready:** per-decision `NN|{json}` stderr log
  in submission/main.py (step, per-option logits, plan commits);
  `rl.kaggle_ingest agent-logs` fetch+cache; postmortem renders logits per
  option. Live from the NEXT submission onward. 56 tests green.
- **Root causes located (exploration, file:line in M19-plan §review):**
  - Over-attach: greedy `score_attach` saturated tier scored a flat 600 > END
    (0) with no surplus penalty; solver never overrides these rows (no prize
    /dev gain) → greedy labels the row. Encoder-side: ATTACH options carried
    ONLY the target's printed features — the net cannot see current energy.
  - No-retreat: greedy escape tier fires only when lethal is already on
    board; solver leaf has no HP-preservation term so defensive retreats
    never clear the override gate. Encoder-side: RETREAT encodes as a bare
    type one-hot (zero informative features).
- **Fixes landed (all twin-mirrored rl/ + tcg/, 469 tests green):**
  - `score_attach`: saturated tier = 600 + dmg-bonus − 150×min(surplus,3) —
    least-fed charged target wins; heavy surplus drops below NON_ATTACKER.
  - `score_retreat` tier 2b: active with prizes_on_KO ≥ 2 at hp ≤ 0.4 and an
    attack-READY bench member → 1450 (below escape-KO 1500, above chip 1000).
  - `encode_option_v2` (rl + tcg twins): ATTACH extra = [target energy/5,
    gap-to-charged-best/5, saturated flag]; RETREAT extra = [damage fraction,
    prizes-at-risk/3, bench-ready flag]. Width UNCHANGED (94; reuses the
    ATTACK-only extra slots — types mutually exclusive).
  - postmortem `[over-attach]` audit flag (saturation attaches; the existing
    attach-off-racer only catches misrouting).
- **Measurements (the load-bearing result of the morning):**
  - Live `[over-attach]` baseline: M18.1 0.75/game, M15 0.45/game (M18-abom
    0.05/g — games too short to accumulate energy).
  - Teacher A/B, 40 greedy lucario-mirror games each (scratchpad m19_ab):
    old 0.10/g over-attach, fixed 0.05/g; retreats taken 0.75/g BOTH arms.
    → **The teacher's own play was mostly clean; the live defect is
    IMITATION FAILURE.** The net is OFFERED retreat 21×/game live and takes
    it 0.11×/game (M18.1; teacher takes 0.75/g) — a 7× gap on an option
    encoded as a bare one-hot. The encoder features are therefore the main
    lever; the teacher-tier fixes tighten the tail (and the save tier adds
    labels greedy never produced).
- **Caveats diaried up front:**
  - Old shards (plan_m15/m16) contain option rows encoded with ZEROS in the
    new extra slots; the M19 mix is ~1/3 new-encoder rows. Accepted for
    M19a; if the net keys on the era difference, re-collect larger.
  - Champion re-measured under NEW encoders would be contaminated (plan5
    trained with zero extras) — gate against the PINNED 2-seed numbers, do
    not re-run plan5 baselines.

**Conclusions (all measured today):**
1. **Class-weight behavior shaping works ON the behavior and monotonically
   costs strength.** Dose-response is clean; the cost scales with weighted
   row fraction (2.2% → −3pp; +10.4% → −10pp). The M18 offline-reweighting
   dead end now generalizes: it wasn't disagreement-weighting specifically,
   it's label-reweighting at high dose.
2. **Plain BC on 1/3-new-encoder data does not learn the new features**
   (m19a flags unmoved) — feature availability alone isn't adoption.
3. All M19 infrastructure stays landed and compounds: NN| net-internals
   logging (live from next ship), teacher fixes (cleaner future labels),
   encoder features (usable by future nets), [over-attach] flag, and the
   defect-measurement harness (scratchpad scripts → 40-game flag counts).
4. **Never read strength from a 40-game flag sample** (m19c 0.475 → 0.331).

**Open residue for M19.2/M20 (Piotr's call, ranked):**
