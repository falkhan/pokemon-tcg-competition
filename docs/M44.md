  engine) and `other` (obs.logs is per-seat; the RESULT log can land in the
  other seat's window). Collector worker returns per-game cause counts;
  `collect()` returns them; `train()` logs TB `loss_cause/*` + `win_cause/*`
  per iteration + one stdout line.
