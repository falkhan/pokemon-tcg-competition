## 2026-07-17 — EI Round 1: REGRESSION 0.314; exploration redesigned

- Collection `data/plan_ei1` (600 games, student osv3_plan0c, τ=1.0 +
  Dirichlet 0.25) + train `osv3_ei1` (val_acc 0.903, plan_acc 0.973) — run
  was externally stopped before the gate; gate rerun after user go.
- Gate `runs/m11_ei1_s1.jsonl`: **0.314** (< 0.415 baseline, gate was ≥0.445).

**Observations / diagnosis:** fidelity went UP (0.886→0.903) while win rate
went DOWN 10pp — the training worked, on the wrong states. Root cause is a
design bug carried from collect_dagger: the student's ACTIONS were
Gumbel-sampled per prompt, stacking per-prompt noise on top of τ=1.0 +
Dirichlet plan noise. Execution was chaotic, so the round's 36k rows are
labels on junk states — capacity spent off-distribution. Per-prompt
exploration is exactly what the buddy lesson prohibits; the thesis is
plan-level exploration with coherent execution.

**Round 2 redesign (dated spec amendment):** (a) EI actions greedy given the
sampled plan — exploration at the plan level ONLY; (b) τ=0.3, no Dirichlet;
(c) student + train init = best checkpoint `osv3_plan0c` (not the regressed
ei1); (d) `data/plan_ei1` QUARANTINED like plan_ei0. Round 2 verdict rules
unchanged: ≥0.445 continues, flat-or-worse = second consecutive miss = kill.

Historic recipe note — **Rung 0'' original diagnosis:** in expert mode, honor
the solver-pilot's own semantics for LABELS — label = line[0] only when
best_score clears MIN_OVERRIDE_SCORE (or the dev margin), else the greedy
pilot's pick; keep deriving the PLAN from the widened line only when it
commits to an attack that clears the bar; execute what we label (teacher
self-play stays consistent). This clones "solver as shipped, plus plan
annotations" instead of "solver with its safety rails removed". ~1h
(recollect 600 + train + gate).
