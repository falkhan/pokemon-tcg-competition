**E0b v1 INVALIDATED + fixed**: v1 printed prize-turns 0/600 for every arm —
impossible next to the wr numbers. Root cause found by tracing: the probe's
`record_turn_end` bailed when the opponent's active was None, and after a KO
the opp active slot is exactly None (awaiting promote) — every prize-taking
turn-end was excluded BY CONSTRUCTION. Fixed (count turn-end + prize fact
first, defer exposure to the first post-promote prompt with both actives);
rerunning n=100/arm. Side finding while tracing: some arm wins vs tuned are
DECK-OUT wins with the arm's prize array untouched at 6 — the M37 dig/deck-out
style, visible offline. (Also: a first debug script briefly implicated the
tuned teacher mutating obs — WRONG, retracted; the anomaly was the debug
script's own prev-init bug counting the setup phase as a 6-prize drain.
Engine arrays verified clean and seat-consistent vs both rule and generic
beds.)
