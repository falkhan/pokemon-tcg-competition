# M10 — Clone the leaderboard (replay imitation): implementation diary

**Status:** ❌ CLOSED NO-GO (started 2026-07-15, closed 2026-07-16, branch
`feature/m10`). Plan reviewed with Piotr 2026-07-15. Both training recipes
killed at G3; root cause: leaderboard teachers' reasoning is unobservable →
fidelity ceiling ~0.53 → imitation doesn't transfer strength. Harvest infra,
converter+gates, meta co-gate (+pinned baselines), deck validation, and the
rl/bc.py training extensions all survive the leg. Lead track returns to M9
Leg 1 ([M9-plan.md](M9-plan.md)); DAgger-on-solver (M9 Leg 2) is the
strongest remaining learning rung.

## Why

Every observable self-teacher caps the student at teacher-strength × fidelity,
and our strongest one (the solver pilot) IS the shipped agent — the whole
BC→DAgger→distillation ladder can approach but never beat it. RL and search on
top are measured dead-ends (M8.3 noise, M8.5 flat sims ladder). The one
untried beyond-teacher path is a STRONGER teacher, and we already collect one:
Kaggle episodes serialize full per-seat observations + the answering action
for BOTH seats, from teams scoring 600–1345 (leaderboard 2026-07-15) against
our ~500. Imitate them.

**Campaign bar:** unchanged 0.55 vs `solver:lucario` @ n≥800 — PLUS the new
G4 meta co-gate (weighted WR over a frozen top-10 harvested-meta deck pool,
each deck solver-piloted) so we stop overfitting the Lucario mirror.

## Conventions

- M8/M9 measurement protocol: screen n=400 (go = +3pp for imitation legs),
  confirm n=800 fresh seed; floors `random:kyogre` ≥0.90 (n=200×2),
  `rule:lucario` no regression vs 0.362.
- Converter gates G0/G1 re-run after EVERY harvest batch (schema drift is the
  #2 risk — all initial verification was against episodes from our own subs).
- Changes land in `rl/` first; `tcg/` twin mirrored post-measurement.

## Ladder

- **G0 — converter audit** (`python -m rl.replay_bc audit`): 100% encode, 0
  out-of-range labels over the whole cache.
- **G1 — roundtrip alignment** (`python -m rl.replay_bc roundtrip`): current
  rules bundle vs itself through kaggle_environments → converter must
  reproduce ≥98% of its own recorded actions (same code both sides).
- **Harvest** (`kaggle_ingest targets` → `refresh --opp-subs ...`): snowball
  the opponent-submission graph toward 1–2k top-team episodes. (Kaggle
  retired the ListEpisodes team filter — probed 2026-07-15, only
  `submissionId`/`ids[]` accepted — so we walk opponents-of-opponents;
  listings DO carry per-agent teamId, captured into episodes.parquet for
  leaderboard cross-referencing.)
- **Build** (`replay_bc build --min-score 550`): shards → `data/bc_kaggle`,
  v2 schema + teacher_score/seat_won/episode_ids, game_id = episode.
- **Train** (recipe ladder): A = fine-tune `osv2_bc2` on
  `[bc_v2b, bc_kaggle]`, score-weighted, lr 1e-4 → `osv2_kbc1.pt`;
  B = replay-only; C (on signal) = from-scratch. Ablation: `--weighting winner`.
- **G2 offline fidelity** → **G3 win-rate screen** → **G4 meta co-gate**
  (`replay_bc meta-eval`), then the usual promotion/ship suite.
